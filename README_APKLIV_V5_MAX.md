# APKLIV TV V5 MAX

UI upgrade on top of V4 without removing the working M3U/M3U8/MPD entry points.

## UI
- Dark IPTV layout
- Dedicated player area
- Search bar
- Category/group selector
- Home / Live / Favorites / History / Playlist / Settings
- Direct M3U file button
- Direct URL button for M3U8/MPD
- Playlist URL button
- Current channel/status panel
- Retry control
- Channel count/status

## Playback
Retains V4:
- HLS/M3U8
- DASH/MPD
- signed query preservation
- per-channel User-Agent / Referer / Origin
- retry
- playlist persistence
- favorites/history persistence

The source remains an Android project. This ZIP is not an APK binary.
